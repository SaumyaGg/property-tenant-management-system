# Property Management Performance Dashboard

## Overview
This project presents interactive Tableau dashboards built on SQL-based analytical views to evaluate revenue performance, invoice risk, tenant payment behavior, occupancy rates, 
and maintenance operations for a property management system.

## Dashboards
### Revenue & Cash Flow
- Monthly Revenue Trend
- Revenue by Property
- Invoice Status Breakdown

### Risk & Operations
- Invoice Risk Heatmap
- Payment Method Distribution
- Maintenance Requests by Category

## Tools & Technologies
- SQL Server / Azure Data Studio
- Tableau
- CSV-based analytical views

## Key Skills Demonstrated
- Data modeling & SQL views
- Dashboard design & storytelling
- Financial and operational analytics
- Data visualization best practices
